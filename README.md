# C Numerical Algorithms & Computations

This repository contains a collection of fundamental numerical methods, mathematical approximations, and computational algorithms implemented entirely from scratch in C. 

The goal of these projects is to demonstrate a deep understanding of mathematical logic and series expansions without relying on standard library functions.

### 🧮 Core Implementations
* **Simpson's 1/3 Rule:** Numerical integration implementation for approximating definite integrals.
* **Taylor Series Expansions:** Custom implementation of the sine wave function.
* **Madhava-Leibniz Series:** Algorithmic approximation of Pi.
* **Combinatorics:** Pascal's triangle generation utilizing factorial logic.
* **Recursive Digital Roots:** Calculating the sum of digits down to a single root using pure recursion.

### 🛠️ Tech Stack
* Language: C
* Focus: Numerical Analysis, Recursion, Algorithmic Math
